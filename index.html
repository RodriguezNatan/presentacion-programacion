  • FUNDAMENTOS DE PROGRAMACIÓN 03

    Primero, una solución precisa

    Programar consiste en expresar una solución mediante instrucciones que una computadora puede ejecutar.

    El algoritmo

    Define pasos finitos, ordenados y sin ambigüedad. Describe qué datos recibe y qué resultado debe producir.

    Antes de escribir código, comprueba la solución con un caso pequeño.

    1. Recibir tres notas válidas.
    2. Sumar sus valores.
    3. Dividir la suma entre tres.
    4. Mostrar el promedio.

    8, 9, 7 → 24 ÷ 3 → 8

    Referencia: cap. 1, Overview, pp. 1–4
  • FUNDAMENTOS DE PROGRAMACIÓN 04

    Tres lenguajes, conceptos comunes

    La sintaxis cambia. Las variables, decisiones, repeticiones y funciones siguen siendo esenciales.

    C

    Tipos explícitos y control cercano de la memoria. Habitualmente se compila a código nativo.

    double nota = 8.5;

    Java

    Tipos explícitos y organización en clases. Se compila a bytecode para la JVM.

    double nota = 8.5;

    Python 3

    Asocia nombres a objetos con tipo. Su intérprete permite ejecutar código conciso.

    nota = 8.5

    Un algoritmo puede implementarse en cualquiera de estos lenguajes.

    Referencia: caps. 3–6 · Matices de ejecución y ejemplos actualizados

    Un entorno para escribir y probar

    El editor guarda el código fuente. Las herramientas del lenguaje permiten ejecutarlo.

    Flujo de trabajo

    1. Editar y guardar el archivo.
    2. Compilar cuando corresponda.
    3. Ejecutar con datos de prueba.
    4. Leer errores y corregir.
    # Terminal: herramientas ya instaladas
# C (GCC)
gcc promedio.c -o promedio.exe
.\promedio.exe

# Java (JDK)
javac Promedio.java
java Promedio

# Python 3 en Windows
py -3 promedio.py

  • FUNDAMENTOS DE PROGRAMACIÓN 06

    La sintaxis da estructura

    Cada lenguaje define reglas para escribir instrucciones, bloques y comentarios.

    // Fragmento de C o Java
if (nota >= 6) {
    nota = nota + 1;
}

# Fragmento de Python 3
if nota >= 6:
    nota = nota + 1

    Detalles que importan

    C y Java delimitan bloques con llaves y terminan muchas instrucciones con punto y coma.

    Python utiliza la sangría para delimitar bloques.

    Un error de sintaxis impide procesar el código. Un error lógico puede producir un resultado equivocado sin detenerlo.

    Referencia: cap. 4, Basic Syntax, pp. 11–16

  • FUNDAMENTOS DE PROGRAMACIÓN 09

    Condicionales: elegir un camino

    Una condición determina qué bloque se ejecuta.

    if promedio >= 6:
    estado = "Aprobado"
else:
    estado = "Por reforzar"

print(estado)

    Dos resultados posibles

    8.0 ≥ 6: la condición es verdadera. El estado será “Aprobado”.

    5.5 ≥ 6: la condición es falsa. Se ejecuta else.

    El umbral de 6 es una regla didáctica de este ejemplo, no una norma universal.

    Referencia: cap. 9, Decisions
  • FUNDAMENTOS DE PROGRAMACIÓN 10

    Bucles: repetir sin duplicar

    Un bucle recorre datos o repite instrucciones mientras se cumpla una condición.

    notas = [8, 9, 7]
suma = 0
for nota in notas:
    suma = suma + nota

# suma: 0 → 8 → 17 → 24

    for y while

    for resulta natural para recorrer una colección.

    while repite mientras una condición sea verdadera. Debe existir una forma de terminar.

    break sale del bucle y continue pasa a la siguiente iteración.

    Pregunta de control: ¿qué pasa si no actualizas el contador de un while?

    Referencia: cap. 10, Loops
  • FUNDAMENTOS DE PROGRAMACIÓN 11

    Arreglos y listas: datos en conjunto

    Los índices permiten acceder a elementos por su posición.

    índice 08
    índice 19
    índice 27
    notas = [8, 9, 7]
primera = notas[0]  # 8
cantidad = len(notas)  # 3

    Una diferencia importante

    Los arreglos de C y Java tienen elementos de un mismo tipo y una longitud que no cambia durante la vida del arreglo.

    La lista de Python puede crecer y contener objetos de distintos tipos.

    Para tres elementos, los índices válidos son 0, 1 y 2. El índice 3 queda fuera.

    Referencia: cap. 13, Arrays, pp. 70–75
  • FUNDAMENTOS DE PROGRAMACIÓN 12

    Cadenas: representar texto

    Una cadena permite almacenar y procesar información textual.

    nombre = "Ana"
mensaje = "Hola, " + nombre
print(mensaje)  # Hola, Ana
print(len(nombre))  # 3
print(nombre[0])  # A

    El texto también tiene estructura

    Concatenar une cadenas. La longitud cuenta elementos y un índice permite consultar una posición.

    En C, una cadena utiliza caracteres y un terminador \0. Hay que reservar espacio para él.

    Java usa String y Python str. En ambos casos las cadenas son inmutables.

    Referencia: caps. 12–14, Characters, Arrays, Strings
  • FUNDAMENTOS DE PROGRAMACIÓN 13

    Funciones: una tarea reutilizable

    Una función recibe parámetros, realiza una tarea y puede devolver un resultado.

    def calcular_promedio(notas):
    if len(notas) == 0:
        return None
    return sum(notas) / len(notas)

resultado = calcular_promedio([8, 9, 7])
print(resultado)  # 8.0

    Un contrato pequeño

    Entrada: una lista de números.

    Salida: el promedio, o None si la lista está vacía.

    Separar el cálculo facilita reutilizarlo y probarlo sin depender de la interfaz.

    Pruebas útiles: una sola nota, todas iguales y una lista vacía.

    Referencia: cap. 15, Functions, pp. 81–87
